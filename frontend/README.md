# HabitFlow

HabitFlow is a habit tracking web app for building consistent routines, monitoring streaks, and reviewing analytics over time.

## Features

- Dashboard with daily habit progress and momentum stats
- Habit creation, editing, and deletion flow
- Progress tracking with check-in history
- Analytics for overview, streaks, and daily trends
- Personalized timezone-aware progress calculations

## Tech stack

- React + Vite
- Tailwind CSS
- Express + Sequelize
- PostgreSQL

## Quick start

1. Install frontend dependencies:
   npm install
2. Start the frontend app:
   npm run dev
3. Start the backend server:
   cd backend
   npm install
   npm run dev

## Notes

- Keep local environment variables in [.env](.env) for runtime configuration.
- The production build output in [frontend/dist](frontend/dist) is generated and safe to regenerate at any time.
